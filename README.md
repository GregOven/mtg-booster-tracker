# MTG Booster Pack Collection Tracker — PRO

A single-file, offline-first web app for tracking a Magic: The Gathering booster pack collection — every set ever released, ownership, prices, release dates, a "plan to buy" list, and full JSON backup/restore.

All data stays in your browser's local storage. Nothing is sent to any server.

## Using it on multiple devices
Since data lives in the browser, it does not sync automatically between devices. Use the **Backup (JSON)** button on one device and **Restore (JSON)** on another to carry your collection across.

Open `index.html` directly, or visit the GitHub Pages link for this repo.
